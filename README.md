# SerialStudio · 嵌入式串口调试助手

面向嵌入式单片机（STM32 / ESP32 / 51 / Arduino 等）开发的现代桌面端串口调试工具，基于 **Python + PySerial + PyWebView (Edge WebView2)** 构建，支持深色/浅色主题切换、高分屏实时波形示波器、常用校验自动追加以及快捷指令管理。

## 核心特性

- **一体化无边框现代界面**：支持深色/浅色双主题切换，自定义标题栏与窗口控制按钮，自适应深色下拉菜单。
- **完备的串口参数与流控**：支持常见及任意自定义波特率（`9600` ~ `2000000+`）、数据位、校验位、停止位、流控（`RTS/CTS`、`XON/XOFF`），以及独立的 **DTR / RTS** 引脚控制。
- **数据监视终端**：
  - ASCII / HEX 十六进制收发切换
  - 毫秒级时间戳、RX / TX / 系统消息语义高亮
  - 实时关键字过滤、暂停接收、导出 `.txt` 日志、RX/TX 字节统计
  - `Ctrl + Enter` 快捷发送、`↑ / ↓` 历史指令翻页、定时自动发送
- **自动校验追加**：发送时可选自动追加 `CRC16-Modbus`、`Sum8`、`XOR8` 校验及行尾结束符（`\r\n` / `\n` / `\r`）。
- **实时多通道波形示波器**：
  - 支持 **文本 CSV / VOFA+ FireWater**（如 `12.3, 45.6` 或 `ch0:12.3, ch1:45.6`）
  - 支持 **JustFloat 二进制协议**（小端 `float32` 数组 + 帧尾 `00 00 80 7F`）
  - 支持最多 8 通道、Y 轴自适应/手动范围、通道显隐开关、鼠标悬停十字准星读数
  - 内置**模拟串口**，无需连接硬件即可体验波形绘制与 `AT` 回环测试
- **快捷指令集**：支持增删改与一键发送，配置保存至程序同级目录的 `quick_commands.json`。

## 使用教程

### 1. 快速开始与连接串口

1. **启动软件**：直接双击 `SerialDebugger.exe`（或通过 `python main.py` 从源码启动）。
2. **选择串口**：
   - 将 USB-TTL（CH340 / CP2102 / FT232 等）或开发板连接到电脑。
   - 在左上角 **串口配置 → 端口** 下拉框中选择对应 `COM` 口；若插拔后未显示，点击右侧 **刷新按钮**。
   - **无硬件体验**：如果没有连接单片机，可选择 **`模拟串口 (内置波形与回环测试)`**，打开后会自动生成 3 路正弦/余弦/三角波测试数据，并支持 `AT` 指令回复 `OK`。
3. **设置参数**：
   - **波特率**：点击输入框或右侧箭头选择常用波特率（如 `115200`、`921600`），也支持直接键盘输入任意自定义波特率（如 `74880`、`1500000`）。
   - **数据位 / 校验位 / 停止位 / 流控**：默认 `8N1`、无流控，适配绝大多数单片机例程。
   - **DTR / RTS**：可根据硬件电路手动拨动开关（例如用于 ESP32/STM32 串口一键下载或触发复位）。
4. 点击 **打开串口**，顶部状态栏变为绿色 `已连接` 即可开始通信。

---

### 2. 收发终端使用

- **HEX / ASCII 切换**：
  - 打开左侧 **接收设置 → HEX 十六进制显示**，收到的数据将以大写十六进制字节显示（如 `AA 55 01 02`）。
  - 打开左侧 **发送设置 → HEX 十六进制发送**，发送区支持输入带空格、逗号或 `0x` 前缀的十六进制字符串（如 `01 03 00 00 00 02`、`0xAA, 0x55`、`AA55`）。
- **自动追加校验与行尾符**：
  - 在 **发送设置 → 自动追加校验** 中可选择 `CRC16-Modbus`、`Sum8` 或 `XOR8`，发送时软件会自动计算并附加到数据帧末尾。
  - 例如发送 Modbus 查询帧 `01 03 00 00 00 02` 并选择 `CRC16-Modbus`、行尾符选 `无`，软件实际发出 `01 03 00 00 00 02 C4 0B`。
- **关键字过滤与日志导出**：
  - 在终端右上角 **过滤关键字** 输入框中输入关键字（如 `ERR` 或 `temp`），可实时筛选终端日志。
  - 点击左侧接收区的 **暂停 / 清空 / 导出**，可将当前终端记录保存为 `.txt` 文件。
- **快捷操作**：
  - 在底部发送框中按 **`Ctrl + Enter`** 快速发送。
  - 在发送框首行按 **`↑` / `↓`** 方向键可翻阅历史发送记录。
  - 开启 **定时发送 (ms)** 并设置周期（最小 `20 ms`），可自动循环发送当前输入框内容。

---

### 3. 实时波形示波器（串口绘图）

切换到顶部 **`实时波形`** 标签页，软件会实时解析串口收到的数据并绘制最多 8 通道曲线。

#### 方式 A：文本 CSV / FireWater 协议（推荐调试阶段使用）

单片机使用 `printf` 按行输出数字即可，支持以下任意格式（以 `\n` 结尾）：

```text
12.34, 56.78, -3.20
temp:25.6, hum:60.2
d:100, 200, 300
```

**STM32 / Arduino C 语言示例**：
```c
float ch0 = 25.4f;
float ch1 = 3.30f;
printf("%.2f,%.2f\r\n", ch0, ch1);
```

#### 方式 B：JustFloat 二进制协议（高频采样 / VOFA+ 兼容）

当采样率较高时，可使用小端 `float32` 数组 + 固定 4 字节帧尾 `0x00, 0x00, 0x80, 0x7F`（将左上角解析协议切换为 **`JustFloat (二进制)`**）：

**C 语言示例**：
```c
float data[2] = {val1, val2};
uint8_t tail[4] = {0x00, 0x00, 0x80, 0x7F};
UART_SendBytes((uint8_t *)data, sizeof(data));
UART_SendBytes(tail, 4);
```

#### 示波器交互技巧
- **通道开关**：点击波形图上方图例中的 `CH0`、`CH1` 胶囊，可单独隐藏或显示某条曲线。
- **Y 轴缩放**：默认开启 `Y轴自适应`；取消勾选后可手动锁定 `最小值 ~ 最大值` 范围。
- **十字准星读数**：鼠标在波形区域移动时，会显示十字准星及当前指针位置的 `Y` 轴数值。

---

### 4. 快捷指令集

切换到顶部 **`快捷指令集`** 标签页，可维护常用 AT 指令或十六进制控制帧：
1. 点击 **`+ 新增指令`** 添加一行，填写名称、指令内容，勾选是否使用 `HEX` 以及行尾结束符。
2. 点击对应行的 **`发送`** 即可一键下发（会自动结合左侧发送设置中的“自动追加校验”）。
3. 修改完成后点击 **`保存配置`**，配置会保存在软件同级目录的 `quick_commands.json` 中，下次启动自动加载。

---

### 5. 界面与快捷键小技巧

- **主题切换**：点击右上角太阳图标，可在 **极夜深色** 与 **清爽浅色** 主题间一键切换。
- **窗口操作**：支持拖动顶部标题栏空白区域移动窗口，**双击标题栏空白处** 可快速最大化 / 还原窗口。
- **状态重置**：点击右上角刷新箭头按钮可一键清零 `RX / TX` 字节统计。

## 常见问题 (FAQ)

- **看不到串口（COM 口）怎么办？**
  请检查设备管理器中是否正常识别端口；使用国产模块通常需要安装 CH340 或 CP210x 驱动，插拔 USB 后点击界面上的刷新按钮即可。
- **打开串口提示“拒绝访问 / Access is denied”？**
  说明该 COM 口已被其他串口工具（如 SSCOM、Arduino IDE 串口监视器、PlatformIO Monitor 等）占用，请先关闭其他软件后重试。
- **在 Windows 上双击 `SerialDebugger.exe` 提示缺少 WebView2？**
  Windows 11 默认内置 Edge WebView2 运行时；极少数精简版 Windows 10 如未内置，安装微软官方 [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 即可。

## 从源码运行

环境要求：Windows 10/11（内置 Edge WebView2 运行时）、Python 3.10+。

```powershell
pip install -r requirements.txt
python main.py
```

## 打包为单文件 `.exe`

```powershell
pip install pyinstaller
.\build_exe.ps1
```

打包完成后可在 `dist\SerialDebugger.exe` 找到独立可执行文件。

## 运行单元测试

```powershell
python -m unittest discover -s tests -v
```
